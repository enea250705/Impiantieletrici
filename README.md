# Punime Elektrike — Landing Page

Landing page në gjuhën shqipe për shërbime punimesh elektrike.

## Përmbajtja

- `index.html` — faqja e plotë (HTML + CSS + JS në një skedar të vetëm, pa varësi)

## Si të shtoni fotot dhe videot

Faqja ka hapësira të gatshme (placeholder) për foto dhe video. Për t'i zëvendësuar:

1. **Foto**: zëvendësoni një bllok `<div class="media-placeholder ...">...</div>` me
   `<img src="foto-juaj.jpg" alt="Përshkrimi" style="width:100%; border-radius:18px;">`
2. **Video**: zëvendësojeni me
   `<video src="video-juaj.mp4" controls style="width:100%; border-radius:18px;"></video>`
